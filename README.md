# Malavika Kashireddy — Portfolio

A lightweight static portfolio site built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Create a new public repository, for example `malavikakashireddy.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and `resume.pdf` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

If the repository is named `malavikakashireddy.github.io`, the site URL will normally be:
`https://malavikakashireddy.github.io/`

## Publish with Vercel
1. Create a new Vercel project.
2. Import the GitHub repository containing these files, or upload the folder.
3. No framework/build command is required; this is a static site.

## Customize
Edit text in `index.html` and visual styles in `styles.css`.
